# LessStutter

a sapiens mod that cuts down on stuttering when loading new areas and hitches while playing on faster speeds

works on both Stable 0.6.1.3 and Unstable 0.7.0.2

it doesn't change anything you'll see in game, it just skips work the game does for no reason. bird song timers for far away trees sleep until you get close, plants that look the same every season don't get visual season change updates, and the game no longer makes a full copy of an object's state every time the server updates it (it only used that copy for debug checks)
